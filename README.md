# ESP32LVGL
Repository for ESP32 Projects

MicroPython LVGL for ESP32 and variants

This GitHub Repository (Repo) provides MicroPython LVGL 9.x information regarding the ESP32. Here are the collected datasheets, firmware and programs for each YouTube video.
