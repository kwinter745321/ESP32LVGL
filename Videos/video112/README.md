# Scope
This is video 112 on an Arduino/LVGL embedded solution. In today’s video we look (Part 3) at LCD Wizard (a commercial product) that creates Arduino, ESPHome, or MicroPython projects. In fact, the Arduino sketch configuration.  For these videos, the owner bumped my account to Pro license. However, all three videos show Non-Pro features and capabilities.  We built the firmware for an ESP32-S3 N16R8 device and the ST7796 display. But you can easily build the firmware for a different ESP32 variant or model. 

We use the LCD Wizard Designer to create a simple Game to showcase the capabilities of the tool.
 
In this video, 
 - Briefly review the LCD Wizard technology.
 - Describe the Test Rig.
 - Demonstrate the Game program.
 - Demonstrate the LCD Wizard designer by walking step-by-step through screen design and layout.
 - Briefly review the custom code using Visual Studio Code.
 - Demonstrate the LCD Wizard export and firmware install using the Arduino IDE.
 - Demonstrate the LVGL program showing the screens.
