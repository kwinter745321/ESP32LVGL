# Scope
This is Video 101, on a Home Assistant ESPHome embedded solution.  It introduces a workflow for creating attractive graphical user interfaces (GUIs) for ESPHome projects using LVGL and a new online tool called the ESPHome LVGL Designer. 

The video is intended to teach makers and Home Assistant enthusiasts how to improve the appearance of ESPHome touchscreen interfaces using the ESPHome LVGL Designer. Rather than focusing on sensors or automation logic, the emphasis is on designing clean, professional-looking GUIs quickly and easily.

In this video,

 - Introduction to ESPHome LVGL Designer 
   - Introduces a free online utility that simplifies the creation of LVGL screens. 
   - Emphasizes how quickly users can build professional-looking interfaces with minimal effort. 
   - Demonstrates a before-and-after transformation of a basic GUI into a polished design. 
 - Hardware Platform 
   - Uses the Cheap Yellow Display (ESP32-3248S035C) as the demonstration hardware. 
   - The device features a 3.5-inch, 320×480 touchscreen integrated with an ESP32. 
   - A GitHub repository provides a ready-to-use device configuration and a simple starter LVGL screen. 
 - Supporting Resources 
   - Covers the hardware layout, wiring for the display and touch controller, and sample ESPHome configuration. 
   - Includes a basic LVGL interface with several widgets that serves as the starting point for the tutorial. 
 - Software Requirements 
   - Recommends using the updated ESPHome Device Builder released in June 2026. 
   - The demonstration was created using ESPHome 2026.7.3 (July release) to ensure compatibility with the example code. 

The code for this video is available at the GitHub site:
https://github.com/kwinter745321/ESP32LVGL/tree/main/Videos/video101
