# Scope
This is video 114 on an MicroPython/LVGL embedded solution. In today’s video we look (again) at the recently released LVGL 9.6.0. But emphasizing ESP32. In this video, we discuss the impact of the release.  We demonstrate our typical test programs and a new program made better by the 9.6 release. Our TestRig is a ESP32-S3 N16R8 board wired to a ST7796 Display.  We also briefly review the code of the game.

In this video, 
 - Demonstrate the button3/matrix3 test programs, and two new programs made better by LVGL 9.6.
 - Briefly describe the impact (in terms of memory needs).
 - Briefly describe the firmware (in terms of Flash storage that remains).
 - Demonstrate the LVGL test_game-go_display.pyprogram showing the stone creation and removal.
